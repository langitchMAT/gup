# 🚀 gup (Git Update & Push)

**gup** — это ультрабыстрая CLI-утилита на Python для автоматизации повседневных Git-рутин (`add`, `pull`, `commit`, `push`) в одну команду с безопасными проверками.

Больше не нужно вручную вводить цепочку из 4 команд при каждом мелком обновлении.

---

## ✨ Особенности

- 🔒 **Защита от утечек:** Проверяет staging перед коммитом на наличие чувствительных файлов (`.env`, `id_rsa`, `.pem` и др.).
- 🔄 **Авто-синхронизация:** Использует `git pull --rebase --autostash`, чтобы подтянуть чужие изменения без создания грязи в истории и без конфликтов с незакоммиченными файлами.
- ⏱ **Авто-сообщение коммита:** Если сообщение не передано, генерирует дефолтное с именем ветки и таймштампом (`auto(main): update 2026-08-24 23:56`).
- ⚡️ **Без внешних зависимостей:** Работает на чистом Python 3 из стандартной библиотеки.
